# Prithvi Raj K — Developer Portfolio

A responsive, self-contained static portfolio for a Python / Django Backend Developer.

## Technology
- Semantic HTML
- Responsive CSS
- Vanilla JavaScript
- Inline-embedded optimized profile portrait and styles for straightforward GitHub Pages publishing

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, set **Source** to **GitHub Actions**.
3. Save. The workflow at `.github/workflows/pages.yml` deploys the site on pushes to `main`.

GitHub Pages is available for public repositories on GitHub Free.
