## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, set **Source** to **GitHub Actions**.
3. Save. The workflow at `.github/workflows/pages.yml` deploys the site on pushes to `main`.

GitHub Pages is available for public repositories on GitHub Free. Documentation: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
